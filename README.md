# Aura Player

A YouTube Music-inspired web music player built with plain HTML, CSS, and JavaScript.

## Features

- Play / pause with pulse-ring animation
- Previous / next track, shuffle, repeat
- Progress seek bar with live time updates
- Volume slider + mute toggle
- Animated visualizer while playing
- Hover-revealed floating play button on each track card
- Active track highlight in red/orange accent theme
- Like/unlike tracks with persistence
- Toast notifications for player actions
- Add your own songs and keep them permanently using IndexedDB (local browser database)

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
